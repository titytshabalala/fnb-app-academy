### Variables and Data Types
- A **variable** is a named container for a value, created using the "=" operator: example *name = 'Junior'*.
- Python has four primitive data types:
    1. str (text in quotes)
    2. int (whole numbers)
    3. float (decimal numbers)
    4. bool (True or False)
- Python detects the data type automatically, when you declare your variable/give value; so you do not declare it explicitly.

- Use *type(value)* to inspect what type Python has inferred.
